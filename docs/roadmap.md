# Civic Pulse Roadmap

## Phase 0: Foundation (Current)
- Establish monorepo structure.
- Configure MongoDB and Models.
- Build Authentication (OTP via TextBee + JWT).
- Establish Basic UI Shells (Landing, Citizen, Authority).

## Phase 1: Intake & Normalization
- Implement multimodal inputs.
- Clean and normalize demands using AI pipelines.

## Phase 2: Hotspots & Thematic Intelligence
- Implement geospatial clustering (`2dsphere`).
- Detect recurring thematic needs using Gemini APIs.

## Phase 3: Evidence & Proposal Generation
- Integrate OpenWeatherMap and demographic APIs.
- Generate automated Development Proposals.

## Phase 4: Prioritization & Impact
- Score proposals based on need vs evidence.
- Predict social and economic impacts.
- Provide constraint-aware Portfolio Optimization.
